# ZError · U校园 AI 版经验仓库

面向 https://uai.unipus.cn/ 的独立网站经验与编译运行包。采用 ZError 通用宿主 API 2，页面规则及后续工作流均保存在本仓库。

当前为基础包：包含网站标识、官网图标、导航图谱、操作经验，以及只读工具 `browser_site_uai__inspect`。登录、课程、播放和答题流程尚未实测，不声明这些能力已经完成。

## 本地开发

使用 Node.js 24 或更新版本：

```sh
npm ci
npm test
npm run dev
```

经验 HTTP 地址为 `http://127.0.0.1:8819/experience.json`。服务仅监听本机，支持 ETag；运行包源码变化后自动重新编译，经验文档按请求读取。可用 `ZERROR_SCRIPT_PORT` 修改端口。客户端校验完整快照后启用新版本，正在执行的工具保持原版本。

## 编译与导入

```sh
npm run build:publish
```

将生成的 `skills/uai/runtime.json` 与同提交的经验文档一起提交。客户端只加载编译产物，不执行仓库源码；产物不进入模型上下文。GitHub Actions 会运行校验、QuickJS 回归，并检查发布产物是否与源码一致。

ZError 支持从仓库链接导入；本地调试时，在该网站设置中使用上面的经验 HTTP 地址。加入 Open 官方目录需要另外登记此仓库，不由本仓库自行更改线上配置。

## 目录

- `skills/uai/`：网站身份、经验、导航图谱、图标和编译产物。
- `src/runtime/`：只读工具及后续经实测的网站工作流源码。
- `scripts/`：构建、开发服务、仓库校验和沙箱回归。

经验只保存经过验证的通用步骤及稳定站内网址，不保存凭据、会话令牌、个人学习数据或具体答案。代码与经验采用 MIT；官网图标仅作网站标识，品牌权利归原权利人。
