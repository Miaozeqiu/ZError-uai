# 登录经验

- 官方入口：https://uai.unipus.cn/ 。先以真实页面核对登录方式和控件。
- 官网 HTML 预加载统一登录组件，公开的登录路由为 `/portal/sso/login`。组件资源来自其他域名不代表该域名已获得凭据授权。
- 账号密码仅通过宿主安全表单与凭据引用传递。脚本和模型不得读取真实密码；用户在普通聊天里输入的密码也不能自动归入其他网站。
- 已保存密码被拒绝或用户要求重填时，调用 `browser_request_credentials` 并传 `replace_rejected=true`。
- 不自动选择未核对的学校、班级、身份认证或付费激活选项。登录后的课程和完成状态以当前页面为准。
- 尚未验证自动登录选择器和成功标记，因此当前仓库不发布专用自动登录工具。
